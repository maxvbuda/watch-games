# Watch Games

A collection of tiny browser games optimized for Apple Watch Safari (and playable anywhere).

**Play:** https://maxvbuda.github.io/watch-games/

To open it on your watch, text yourself the link and tap it in Messages on the watch.

Every game lives in `games/<id>.html` and is registered in `js/games.js`.
Shared styles are in `css/watch.css` and helpers (canvas, input, overlays, best scores) in `js/common.js`.
